# 青果ポップ（SeikaPop）

青果店の朝、その日入荷したおすすめを**スマホだけで**すぐ電子ポップにするWebアプリ（PWA）。
iPhone・Android どちらもブラウザで動き、ホーム画面に追加するとアプリのように使える。

## できること（0.1.0 試作）

- 撮影または写真を選ぶと、**自動で明るく・おいしそうに補正**（手で微調整も可）
- 見本の上を**指で動かして位置合わせ、2本指で拡大**
- デザイン4種: 金額主役（チラシの1コマ風に価格を大きく。余白は上下左右とも同じ幅）／写真主役／段ボール手書き／シンプル上品。
  店名はポップに入れない（フレームの下の帯で入れる）
- サイズ3種: 正方形（LINE・Instagram）／縦 4:5（Instagram投稿）／縦長 9:16（ストーリーズ）
  ＝**同じ中身から別のサイズを出し直せる**（画像ではなくデータで持っているため）
- **日付はポップ1枚には入れず、フレーム（広告）の下の帯にだけ入れる**（同じポップを日をまたいで使い回せるように）
- ポップ1枚に入れるのは **産地（食品はメーカー名）・商品名・価格・単位** だけ。青果にも食品にも使う。
  単位は**候補をタップで入る**（1袋・1パック・1人前・1本入・1個入 など）。見出しと日付はフレームで入れる。
  「メモ」は画像に入らない（入荷数などの控え。古いポップの「ひとこと」もここに出る）
- **レギュラー**: 履歴の良いものを「★ レギュラーにする」でレギュラー欄へ移す → タップ1回で今日のポップを作る。
  レギュラーから作ったときは「今日の価格・産地を確認しました」に印を付けるまで出せない
  （前回の価格・産地のまま出す事故を防ぐ）
- **共有する**: スマホの共有画面から LINE・Instagram・写真アプリへ（共有に対応しない端末は画像を保存）
- 価格は**税抜・税込を選んで**入れる。税抜なら設定の税率（初期値 8%）で計算した税込を必ず併記する（総額表示）。
  税込の端数は設定で「小数第2位まで（117.72円）／切り捨て／四捨五入」。小数の部分（.72）は小さく描く
- 価格の欄の左の **「各」** に印を付けると、価格の数字の左下に小さく「各」を重ねる（同じ値段の品をまとめて出すとき）
- **商品名の書体**を候補から選べる（極太ゴシック・丸ゴシック・明朝・マジック書き・ポップ・筆文字・まる文字・手書き など約20種。選ばなければデザインのまま）
- 写真の仕上げに **「まわりをぼかす」**（写真の外周をデザインの下地の色へぼかす。写真主役は暗い色へ）・ **「セピア調」**（少しだけセピアに寄せる）・ **「フィルム風」**
  （コントラスト -25・黒レベル +20・シャドウ +25・ハイライト -15・彩度 -20・色温度 +20・粒子 +40・周辺減光 -15。値は `js/image.js` の `VINTAGE`）のチェック。
  写真の補正の「自動補正」「補正なし」では外れない
- **はじめの画面**: いちばん上に入口が2つ。「＋ 1枚作る」（ポップを1枚）と「🧩 フレームにまとめる」（作った画像を並べて1枚にする広告）。
  その下は**レギュラー**と**履歴**（作ったポップ。タップで続きを直す・もう一度出す）の2つの欄だけ
- **作った画像**: 共有・保存した画像（と「履歴に残すだけ」を押した画像）を控える。
  新しい60枚まで残す（スマホの容量を食い尽くさないため）。ただし各レギュラーの最新の1枚は数えず残す
- **フレームにまとめる**（広告）: ①フレームを選ぶ（1枚・2枚横並び・2枚縦並び・3枚大1小2・4枚田の字。特売が1品なら1枚。
  **「＋ カスタムを作る」**は6行のボタンの空のフレームから始め、写真を入れたい行のボタンを押して 1〜3 枚を選び、見出しの帯のボタンで色（濃い青・黒・赤・緑・オレンジ）を選び、名前を付けて「保存して使う」。
  押さなかった行は使わない。例: 1行目1枚・2行目2枚・3行目3枚 → 3行6枚。写真どうし・左右の端・上下の帯との隙間は 5px、
  枠は正方形で、行が多いほど縦に長くなる。保存したものは「★ 名前」で何度でも選べ、直す・削除もできる（バックアップにも入る）。
  形は `frames.js` の `customFrame`）→ ②はじめの画面と同じポップ（レギュラー・履歴。並べ方は `popLists`）からタップした順に枠へ入れる。
  枠の画像は選んだポップの**今の中身からその場で作る**（直したものがそのまま入る。書き出していないポップも選べる）。
  レギュラーから作って価格・産地の確認がまだのポップは「確認待ち」で入れられない
  → ③見出しを選んで共有・保存。ポップの画像は**切らずに枠へ丸ごと収める**（価格・税込が欠けないように）。
  全部の枠が埋まるまで出せない。作った広告も履歴に残る
- 打つたびに自動保存。バックアップの書き出し・読み込み（設定画面。作った画像の履歴も含む）
- **事務所へ集める**: 共有・保存・履歴に残したポップを、法人の Google ドライブへ自動で送る（操作は増えない）。
  送れなかった分は端末に控えて、開いたとき・電波が戻ったときに送り直す。同じポップは最新の1件にまとめる。
  事務所が配る設定用リンクを貼り付けるだけで設定できる。受け取り口の設置は `tools/collector/README.md`
- **写真ストック**: 同じ受け取り口で、ドライブの「青果ポップ 写真ストック」フォルダを、どの端末からでも呼び出せる写真の置き場にする（費用なし）。
  PC の担当はドライブのフォルダへ写真をドラッグして入れる。現場では編集画面の「📤 この写真をストックに入れる」（控えて送る）。
  編集画面の「📦 ストックから」で一覧（前に読んだ一覧をすぐ出し、裏で最新に入れ替える・名前で探せる）→ タップでそのポップの写真になる。
  画面は `js/views/stock.js`、通信は `sender.js`、判定は `collect.js`、受け取り口は `tools/collector/Code.gs`
- 電波が弱くても開ける（一度開けば本体と書体を端末に控える）

## 毎朝の流れ

1. はじめの画面で**レギュラーをタップ**（初めての商品は「＋ 1枚作る」→ 📷 撮影）
2. 価格・産地を直して、確認の印を付ける（写真を撮り直してもよい）
3. 「共有する」→ LINE / Instagram

## 試し方

### PCで見る

**`start.bat` をダブルクリック**（ブラウザで**作業場**が開く。黒い窓は出ない。使い終わったら作業場の右上「終了」で止める。
止め忘れても害は無く、次に `start.bat` を開くと動いているものをそのまま使う。動きの記録は `tools/serve.log`）。

作業場（http://127.0.0.1:8765/tools/）は PC でする作業の入口で、「ポップを作る・試す」「金額主役の見た目を直す」
「価格の描き方を外部AIに頼む」「事務所へ集める準備」の箱ごとに、開く画面と順番を並べている。
いちばん上の「スマホで開くアドレス」には公開版のアドレスと、`start-lan.bat` で起動したときは同じ Wi-Fi 向けのアドレス
（`tools/serve.py` の `/api/info` が教える）を出し、「コピー」1回でクリップボードへ入れられる（LINE などに貼って送る）。
各画面の左上「← 作業場」で戻る。アプリだけはスマホと同じ画面なので戻り口を付けず、別のタブで開いて作業場のタブを残す。画面を足したら作業場にも足すこと。
GitHub（公開版・リポジトリ・公開の進み具合）・Apps Script（受け取り口）・ドライブ（集まったポップ）は、
作業場の「メンテナンス」から新しいタブで開く。Apps Script とドライブの直接の行き先は法人ごとに違うのでリポジトリには書かず、
作業場の「直接開く先を登録する」でその PC のブラウザに覚えさせる（未登録のあいだは一覧・検索の画面が開く）。
「法人の Google アカウントを登録する」にメールアドレスを入れると、Google の画面はそのアカウントで開く
（`authuser=メールアドレス` を付ける。登録しないと Chrome のいつものアカウント＝個人用で開いてしまう）。

| アプリ | http://127.0.0.1:8765/ |

ファイルを直したらブラウザで再読み込み（F5）すれば反映される（`tools/serve.py` はブラウザにファイルを控えさせない。
`python -m http.server` だと古いJSが残って「直したのに変わらない」ことがある）。
コマンドで起動するなら `python tools/serve.py`。

### スマホで見る（2通り）

| 方法 | 手間 | 動くもの |
|---|---|---|
| **同じWi-FiのPCから配る**（`start-lan.bat` で起動し、窓か作業場に出るアドレスをスマホで開く） | すぐ。初回にWindowsのファイアウォールの許可が出る | 撮影・作成・保存は動く。**共有ボタン・ホーム画面のアプリ化・オフラインは動かない**（HTTPS でないため。代わりに画像を保存する） |
| **HTTPS で公開する**（GitHub Pages・Cloudflare Pages など。無料） | アカウントと公開の設定が要る | すべて動く。本番もこの形 |

## 開発

```bash
npm test        # 計算部分のテスト（node --test。インストール不要）
npm run lint    # oxlint（初回は自動で取得）
python tools/make_icons.py   # アイコンを作り直す（Pillow）
```

ビルドは無い（素の HTML / JavaScript モジュール）。外部ライブラリも使っていない。

| ファイル | 中身 |
|---|---|
| `js/model.js` | ポップのデータ・レギュラーの使い回し・価格の読み取り（純粋な関数） |
| `js/layout.js` | 写真の切り出し・指の移動・文字の折り返し（純粋な関数） |
| `js/image.js` | 写真の縮小・自動補正・セピア調 |
| `js/templates.js` | 4つのデザイン |
| `js/frames.js` | 広告のフレーム（データ）と、枠への画像の入れ方・出力を止める判定（純粋な関数）。**フレームの足し方は冒頭のコメント** |
| `js/catch-design.js` | 金額キャッチのデザイン（数値・色・書体。`tools/designer.html` の「保存」で書き換わる。前の版は `tools/designer-backup/`） |
| `js/label-design.js` | 「金額主役」の産地・商品名・数量と単位の3行のデザイン（書体・大きさ・色・縁取り・背景の帯・置き場所。`tools/designer.html` の「保存」で書き換わる） |
| `js/labels.js` | 3行の置き方・描き方・保存前の検査 |
| `js/price-design.js` | 「金額主役」の価格部分（外部AIの案と入れ替える。手順は `tools/price-kit/PROMPT.md`） |
| `js/render.js` | 描画・画像ファイル化 |
| `js/store.js` | 保存（今は端末内の IndexedDB）。**クラウド化するときはここを差し替える** |
| `js/backup.js` | バックアップの検証・重ね合わせ |
| `js/collect.js` | 事務所へ集める仕組みの判定（設定用リンクの読み方・送る控え・受け取り口の返事・写真ストックの名前と検索。純粋な関数） |
| `js/sender.js` | 事務所へ送る（控えを順に送る・送れなければ理由を残して次の機会に） |
| `tools/collector/` | 受け取り口（Google Apps Script の `Code.gs`）・設置手順・設定用リンクを作る画面 `link.html` |
| `js/views/*.js` | 画面（はじめ＝レギュラーと履歴・編集・設定・フレームにまとめる＝広告） |
| `sw.js` | オフライン用の控え（ファイルを足したら `SHELL` に足して `VERSION` を上げる） |

## この先（案）

1. **どのスマホからでも同じ場所を見る**: `store.js` と同じ関数を持つクラウド版を作る
   （候補: Supabase・Firebase・Cloudflare の無料枠。写真の置き場所とログインが要る）。
   今はスマホ1台の中なので、機種変更の前はバックアップを書き出すこと。
   ※ iPhone はホーム画面に追加していないサイトの保存を、しばらく開かないと消すことがある
2. **AIで手間を減らす**: 写真からキャッチコピーの候補を出す・段ボールの手書きPOPを撮って文字を読み取る
   （APIキーを端末に置けないので、1 のサーバー側に置く）
3. **公式LINE・Instagram へ直接出す**: 公式LINEのアカウントができたら配信の連携を足す
   （今は共有ボタンで手で出す）
